# Jarvis Financial Analysis

This repository contains the financial analysis and valuation model for **Jarvis consulting Corp.**, as detailed in `Jarvis.xlsx`.

## Overview
The `Jarvis.xlsx` workbook is a comprehensive financial model covering the fiscal years **FY19 through FY23**. It includes core financial statements, comparative valuation metrics, and funding strategies, with figures presented in Rs. Crores.

## File Structure (`Jarvis.xlsx`)
The workbook is organized into the following key sections/sheets:

1. **Case Introduction**
   - Overview and context of the Jarvis consulting Corp. financial case.
   
2. **Core Financial Statements (FY19 - FY23)**
   - **P&L (Profit & Loss):** Contains revenue breakdown (Net Sales, Cost of Sales, Gross Profit) and operating expenses.
   - **Balance Sheet:** Details of the company's Current and Non-Current Assets (e.g., Cash, Receivables), Liabilities, and Shareholder Equity.
   - **Cash Flow:** Breakdown of cash flow into Operating Activities (reconciliation of Net Profit), Investing Activities, and Financing Activities.

3. **Financial Analysis**
   - **P&L Analysis Sheet & BS Analysis Sheet:** Advanced breakdown, trend analysis, and schedules for the Income Statement and Balance Sheet across the 5-year period.

4. **Valuation & Funding**
   - **Relative Valuation:** Market data and comparable company analysis. Includes peer metrics such as EV (Enterprise Value), CMP (Current Market Price), Shares Outstanding, Revenue, EBITDA, and Valuation multiples (Price/Revenue, EV/EBITDA, EV/EBIT).
   - **Funding Plan:** Details capital requirements and financing strategies structured in Rs. Crores.

## Usage
This file is intended for financial analysts, investors, or management to assess historical performance (FY19-FY23), evaluate peer valuations, and review capital funding structures. Ensure that iterative updates to market assumptions are done in the *Relative valuation* and *Funding plan* sheets.
